MAYLANDS MEADOW — CLIENT SITE
=============================

To view: open index.html in a browser.
To publish: upload the whole folder. index.html must sit beside /images and /fonts.

ADDING THE PLANT PHOTOGRAPHY
----------------------------
The plant cards currently show a tinted plate keyed to each plant's flower
colour. To use the real photos from the Notion plant database:

  1. Export or download each plant photo from Notion.
  2. Name each file with the slug in images/plants/FILENAMES.csv
     e.g.  tall-verbena.jpg,  chocolate-lily.jpg,  lambs-ear.jpg
  3. Drop them into  images/plants/
  4. Landscape 4:3 works best, around 1200px wide.

No rebuild is needed — the page picks up any file that matches. Anything
still missing keeps its tinted plate, so a partial set looks deliberate.

(These could not be pulled automatically: this workspace's network blocks
Notion's file host, so the photos have to come across by hand.)
