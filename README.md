## What this package contains

Four clean URL pages designed to replace the old Framer paths now returning 404s:

- /garden-design/
- /ecological-garden-design-melbourne/
- /garden-installation/
- /plant-donation-program/

Also included:

- sitemap.xml
- robots.txt

## How to install on GitHub Pages

Copy each folder into the root of the GitHub Pages repository, so the structure looks like:

garden-design/index.html
ecological-garden-design-melbourne/index.html
garden-installation/index.html
plant-donation-program/index.html
sitemap.xml
robots.txt

Commit and push.

Then test:

https://www.gardenerandson.com/garden-design/
https://www.gardenerandson.com/ecological-garden-design-melbourne/
https://www.gardenerandson.com/garden-installation/
https://www.gardenerandson.com/plant-donation-program/

## Important

Because these pages exist at the old paths, Google and visitors should stop receiving 404s. If you ever move them again, use a proper server-side 301 redirect where possible.
