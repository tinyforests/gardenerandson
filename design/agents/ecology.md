# Ecology agent — Ecology

Find the place the garden belongs to.

- Use Find My EVC (findmyevc.com) or the same DEECA lookup it uses for the site address.
  Fill `evc_code`, `evc_name`, `bioregion`. If the address is incomplete, ask in `questions`.
- `reference`: 15–30 reference species for that EVC from the canonical plant library
  (ecologicalregistry.org/data/plant-library.json, `evcs` field), grouped by layer: canopy,
  shrubs, grasses and strappy, forbs, groundcovers. Botanical name and common name.
- Check the site stage: drop canopy species if the garden already has mature canopy, and note
  shade-tolerant understorey species when trees cover most of the area.
- `habitat`: nearby reserves, creeks and registered gardens worth connecting to.
- `observations`: fauna recorded on site or seen in the photos.
