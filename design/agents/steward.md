# Steward agent — Registry

Prepare the garden for the Ecological Registry after install.

- Read the registry-figures skill before quoting any Registry number.
- Gather the inputs the Registry assessment needs from the project: area (sum of `areas`),
  species planted (Plant Studio list), canopy and layers, habitat features, photos.
- Draft the enrolment as a PR on tinyforests/reg (or the assess.html inputs in `notes`), never
  merged by the agent. The garden's precise address and steward names never go in the public repo.
- Draft the steward welcome email via the Comms brief.
- `garden_id` only once the Registry has issued it; until then leave it out and say so.
