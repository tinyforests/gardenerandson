MAYLANDS MEADOW — STUDIO PRESENTATION
=====================================

RUNNING IT ON THE 43" STUDIO LED
--------------------------------
  1. Plug in the LED and set it as an EXTENDED display (not mirrored).
  2. Open index.html on the laptop. This is the presenter view.
  3. Click "Open display window".
  4. Drag that new window onto the LED, click it, press F for fullscreen.
  5. Click back on the laptop window and drive from there.

The two windows stay in sync. Notes, timer and the next-slide preview stay
on the laptop and never appear on the LED.

KEYS
----
  <- ->      previous / next slide
  space      next slide
  B          blank the LED (talk without the screen pulling focus)
  T          reset the timer
  P          pause / resume the timer
  F          fullscreen
  Home/End   first / last slide

If the display window ever falls out of step, press <- then -> to resync.

16 slides. The flowering calendar builds itself from the same plant data as
the A3 sheets and the client site, so the three can never disagree.
