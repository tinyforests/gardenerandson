# Garden presentations

Each new garden lives in a named folder containing its minisite and local assets.

- `ruffey/`: Under the Canopy client minisite; `deck/` is the Ruffey presenter deck, with shared parent assets.
- `maylands/`: Maylands Meadow minisite; `deck/` contains the presentation and the preserved alternate `index2.html`. Both deck versions share the parent fonts and images.
- `victoria/`: existing presentation and client pages.
- `ashmore.html` and `ashmoreroad.html`: existing variants with different presenter behaviour; both retained.
- `curlewis.html`: existing presentation.

Old `/decks/`, `/maylands/` and `/maylands/deck/` URLs redirect to their corresponding new locations and preserve query strings and fragments. Original high-resolution image files remain in the source directories outside this website repository.
